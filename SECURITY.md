# Security reports

The latest published release is the supported version. Fixes are delivered through new releases; update before reporting a problem.

For a sensitive vulnerability, use the repository's private vulnerability reporting option when available. Otherwise open a minimal issue asking the maintainer for a private reporting channel, without exploit details or private data. Do not post passwords, email contents, screen captures, or authentication tokens in a public issue.

Include the affected version, operating system, steps to reproduce, and a description of the impact. Blip does not collect telemetry or upload screenshots. Gmail access is optional and uses credentials supplied by the user. Third-party dependencies have their own maintainers and licenses.
