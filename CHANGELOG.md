# Changelog

## 0.1.0 — 2026-11-25

- Initial Sun Wukong desktop companion with Canvas artwork and optional PNG spritesheets.
- Transparent, always-on-top window, bottom-edge movement, cursor tracking, jump/bounce animation, and staff spin.
- Tray and character menus with encouragement, jokes, emoji check-ins, hide/restore, and clean shutdown.
- Optional read-only Gmail alerts and user-initiated local screen capture/PNG export.
- Rotating diagnostic logs, installable Python package, desktop build tooling, and GitHub CI/release workflows.
- Windows desktop behavior tested locally. macOS and Linux desktop support is experimental.
